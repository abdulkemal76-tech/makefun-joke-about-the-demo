Entry for the make.fun bounty [The joke about the demo](https://make.fun/bounty/the-joke-about-the-demo-20261121-0551): a program that writes a one-line joke about working beside AI coding agents to `/output/entry.txt`.

## Run

```sh
python3 main.py
```

`main.py` (Python 3.13, standard library only) writes the joke to `/output/entry.txt` — one line, 124 characters, no network needed.

## The joke

> During the demo my AI agent crashed the app, then replied to its own error message: 'Great question, let me look into that.'
